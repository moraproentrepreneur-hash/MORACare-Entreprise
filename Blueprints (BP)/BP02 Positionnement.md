# 1. Objet du document

Ce document définit le positionnement stratégique de MORACare Enterprise.

Il précise les problèmes que la plateforme résout, les utilisateurs auxquels elle s'adresse, sa proposition de valeur, son périmètre fonctionnel et les principes qui guident son évolution.

Toutes les décisions concernant le développement, la commercialisation et les futures évolutions devront rester cohérentes avec ce positionnement.

---

# 2. Définition du produit

MORACare Enterprise est une plateforme SaaS de gestion des établissements de santé.

Elle centralise, dans un environnement unique, toutes les opérations médicales, administratives, organisationnelles et financières nécessaires au fonctionnement quotidien d'un établissement de santé.

Le logiciel est accessible via un navigateur web, sans installation locale, avec une architecture Cloud sécurisée.

---

# 3. Catégorie du produit

MORACare appartient à la catégorie des ERP (Enterprise Resource Planning) spécialisés dans le secteur de la santé.

La plateforme n'est pas uniquement un logiciel de consultation médicale.

Elle constitue un système d'information complet permettant de piloter l'ensemble des activités d'un établissement.

---

# 4. Les problèmes que MORACare résout

La plateforme répond notamment aux difficultés suivantes :

- multiplication des registres papier ;
- dispersion des informations entre plusieurs logiciels ;
- perte de temps lors des recherches de dossiers ;
- erreurs administratives ;
- absence de traçabilité des actions ;
- mauvaise communication entre les services ;
- difficultés de suivi des paiements ;
- mauvaise gestion des hospitalisations ;
- absence de statistiques fiables ;
- gestion complexe des utilisateurs et des permissions.

---

# 5. Proposition de valeur

MORACare permet à un établissement de santé de gérer l'ensemble de son activité depuis une seule plateforme.

La solution apporte :

- une vue centralisée de l'établissement ;
- une meilleure organisation ;
- une réduction des tâches répétitives ;
- une meilleure qualité des données ;
- une meilleure collaboration entre les équipes ;
- une sécurité renforcée ;
- une prise de décision facilitée grâce aux tableaux de bord.

---

# 6. Ce que MORACare n'est pas

Afin d'éviter toute dérive fonctionnelle, MORACare n'a pas vocation à devenir :

- un logiciel de comptabilité générale ;
- un logiciel de paie complet ;
- un logiciel de gestion pharmaceutique nationale ;
- un système de télémédecine ;
- un outil de création de sites web ;
- un logiciel bureautique.

Ces domaines pourront faire l'objet d'intégrations ou de modules complémentaires sans modifier le cœur du produit.

---

- cabinets médicaux ;

- cabinets spécialisés ;

Chaque type d'établissement pourra activer uniquement les modules correspondant à son activité.

---

# 10. Périmètre géographique

MORACare est conçu pour être déployé dans n'importe quel pays.

La plateforme doit permettre :

- la gestion de plusieurs langues ;
- la gestion de plusieurs devises ;
- la personnalisation des formats de date ;
- la personnalisation des fuseaux horaires ;
- l'adaptation aux réglementations locales ;
- la personnalisation des documents administratifs.

Aucune fonctionnalité ne devra être limitée à un pays particulier.

---

# 11. Positionnement concurrentiel

MORACare se distingue par :

- une architecture modulaire ;
- une interface moderne et intuitive ;
- une gestion avancée des rôles ;
- une configuration flexible selon les établissements ;
- une plateforme SaaS accessible sans installation ;
- une évolutivité permettant d'ajouter de nouveaux modules sans refonte.

La priorité n'est pas de proposer le plus grand nombre de fonctionnalités, mais de proposer des fonctionnalités cohérentes, fiables et parfaitement intégrées.

---

# 12. Principes de différenciation

Chaque fonctionnalité développée devra respecter les principes suivants :

- simplicité d'utilisation ;
- réduction du nombre de clics ;
- automatisation des tâches répétitives ;
- cohérence entre les modules ;
- sécurité des données ;
- performances constantes ;
- évolutivité.

Toute fonctionnalité qui ne respecte pas ces principes devra être réévaluée avant son développement.

---

# 13. Vision commerciale

MORACare est distribué sous forme d'abonnement SaaS.

Le modèle économique repose sur plusieurs niveaux d'abonnement permettant à chaque établissement de choisir une formule adaptée à sa taille.

Les limitations éventuelles concernent les fonctionnalités ou les capacités prévues par la politique commerciale, sans remettre en cause l'intégrité de l'architecture logicielle.

---

# 14. Évolutivité

Le positionnement de MORACare impose que toute nouvelle fonctionnalité puisse être ajoutée sans modifier les fondations du système.

L'architecture devra permettre :

- l'ajout de nouveaux modules ;
- l'intégration de nouveaux services ;
- l'ajout de nouvelles API ;
- l'intégration de partenaires ;
- l'évolution des réglementations ;
- l'internationalisation de la plateforme.

---

# Conclusion

MORACare Enterprise est un ERP SaaS spécialisé dans la gestion des établissements de santé.

Son positionnement repose sur une plateforme unique, modulaire, sécurisée et évolutive, capable d'accompagner des établissements de toutes tailles tout en conservant une expérience utilisateur simple, cohérente et fiable.

Toutes les décisions prises au cours du développement devront rester conformes à ce positionnement.
