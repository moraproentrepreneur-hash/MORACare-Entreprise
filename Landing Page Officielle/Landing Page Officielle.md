# 1. Objectif

La Landing Page de MORACare Enterprise a pour objectif de convertir les visiteurs en prospects qualifiés.

Elle doit permettre à un directeur d'établissement, un médecin responsable ou un gestionnaire de comprendre immédiatement :

- ce qu'est MORACare Enterprise ;
- les problèmes qu'il résout ;
- les bénéfices pour son établissement ;
- pourquoi choisir cette solution ;
- comment demander une démonstration.

La landing page ne cherche pas à tout expliquer.

Elle cherche à donner envie.

---

# 2. Public cible

La page s'adresse principalement à :

• Cabinets médicaux

• Cliniques privées

• Centres médicaux

• Hôpitaux

• Laboratoires

• Centres d'imagerie

• ONG médicales

• Ministères de la Santé

• Structures de santé publiques

---

# 3. Objectif principal

Le visiteur doit réaliser UNE seule action :

→ Réserver une démonstration

Objectifs secondaires :

• Demander un devis

• Contacter un conseiller

• Découvrir les fonctionnalités

# 9. Conversion

La landing page doit être conçue pour maximiser le taux de conversion grâce à :

• CTA visibles à plusieurs endroits
• Messages clairs
• Preuves de confiance
• Présentation des bénéfices avant les fonctionnalités
• Parcours utilisateur simple
• Formulaire de demande de démonstration court et intuitif

# 10. Résultat attendu

À l'issue de sa visite, le prospect doit :

✓ comprendre la valeur de MORACare Enterprise ;

✓ identifier rapidement les fonctionnalités qui répondent à ses besoins ;

✓ avoir confiance dans la solution proposée ;

✓ souhaiter prendre contact avec MORA Shawiri pour une démonstration ou un devis personnalisé.
